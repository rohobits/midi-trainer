# Research: gamification and feedback mechanics

Compiled 2026-09-25 from web search. Most vendor pages were unreachable from the research
container, so entries rely on search excerpts and cited secondary sources; numbers marked
"community-measured" come from forums or wikis rather than official documentation.

## Instrument-learning apps with real-instrument input

| Product | Key mechanics |
|---|---|
| **Yousician** | Mic pitch+timing. Per song part 1 silver → 3 gold stars; gold needs every note right with good timing. Practice (slow/wait) vs Play (scored). Path → levels 1–10+ → Missions (songs, videos, trainers). Weekly Challenge: everyone plays the same song at several difficulty levels, leaderboards My level / Global / Friends. Weekly streaks, session goal in stars or minutes, 30-day challenge, follow/friends, level certificates. Premium vs Premium+ (licensed songs) ≈ $19.99/mo or $119.99/yr; family plan. Sources: [scoring](https://support.yousician.com/hc/en-us/articles/208014795-Song-scoring-and-leaderboards), [path](https://support.yousician.com/hc/en-us/articles/206930639-How-the-guitar-learning-path-works), [pricing](https://www.guitarchalk.com/yousician-cost/), [weekly challenge](https://www.pianodreamers.com/yousician-piano-review/) |
| **Melodics** (pads/keys/drums, MIDI) | Closest analogue. Per-hit colour: green on time, orange early, purple late, red missed. Lesson scored /100 on timing, streaks, early/late/missed → pass/fail; stars; ≥2 stars earns a collectible "Record" organised into albums. Courses → Grades → Steps (one concept each). Practice Mode: loop region, slow down, Auto-BPM (raises tempo as you succeed), Wait (pauses until the correct hit). Daily Goal 5 min; consecutive goals → Streak; Trophies at 3/5/7/10…60 goal-days with progress bar. Progress screen: level, stars, records, streaks, per-attempt improvement. Cites Deep Practice (Coyle/Ericsson): chunk, repeat, slow down; "5 min/day, 4×/week". Standard vs Premium (song lessons) ≈ $29.99/mo or $149.88/yr; sold via retailers and bundled with controllers. Sources: [how it works](https://melodics.com/how-it-works), [streaks](https://support.melodics.com/en/articles/6777043-what-are-streaks), [trophies](https://support.melodics.com/en/articles/6777037-what-are-trophies), [records](https://support.melodics.com/en/articles/6777048-what-are-records), [practice mode](https://support.melodics.com/en/articles/6777027-practice-mode), [deep practice](https://melodics.com/blog/index.php/2017/12/15/deep-practice-how-it-can-help-you-get-results-faster/), [playbook](https://melodics.com/blog/playbook), [pricing](https://subger.com/en/us/service/melodics) |

Master Mode hides notes after repeated success. Score Attack with strikes. Guitarcade mini-games per technique. Sources: [difficulty](https://steamcommunity.com/app/221680/discussions/0/1644304412653328081/), [Riff Repeater](https://steamcommunity.com/app/221680/discussions/0/558749190898705565/), [60-day study](https://venturebeat.com/games/ubisofts-rocksmith-2014-video-game-may-be-the-fastest-way-to-learn-the-guitar-interview/) |
| **Rocksmith+** | Real-time accuracy %, Adaptive Difficulty, Riff Repeater, account level unlocking cosmetics, Workshop for community arrangements of library songs. $19.99/mo, $139.99/yr. Sources: [Steam](https://store.steampowered.com/app/2834910/Rocksmith/), [Workshop FAQ](https://www.ubisoft.com/en-us/game/rocksmith/plus/rocksmith-workshop/tutorials/reference/faq), [adaptive difficulty](https://www.ubisoft.com/en-us/help/rocksmith-plus/gameplay/article/adaptive-difficulty-in-rocksmith/000097506) |
| **Simply Piano / Guitar** | 0–3 stars per song section; Star Levels show "stars earned / recommended before continuing" (soft gate); practice waits for the correct note; tempo slider. ~$15/mo. Sources: [star levels](https://piano-help.hellosimply.com/en/articles/7943591-understanding-star-levels), [basics](https://piano-help.hellosimply.com/en/articles/7943490-learning-with-simply-piano-the-basics) |

## Synthesised mechanics → DJ trainer (TS = table stakes, D = differentiator, L = later)

**Scoring and feedback**
1. Tiered judgements with published ms (TS): Perfect ±40 / Great ±90 / OK ±140 at default strictness; one knob scales all.
2. Early/late colour per hit (TS); distinguish wrong control from right control wrong time.
3. Score /100 + medals bronze 80 / silver 90 / gold 96 (TS).
4. Combo multiplier with reset (TS for performance mode, off in lessons).
5. Star power / Euphoria charged by clean phrases (L).
6. Continuous-control scoring: fader reach + curve shape, knob value at beat, jog convergence (D; nobody ships it).
7. Freestyle sections scored for activity (D/L).

**Difficulty adaptation**
8. Wait mode (TS). 9. Section loop + slow-down (TS). 10. Auto-BPM ladder with the Rocksmith 80/90/100 rule (D). 11. Dynamic density 1–100 (D). 12. Strictness setting, Precision mode later (TS/L). 13. Master mode hiding the highway (D). 14. Adaptive placement test (L).

**Curriculum**
15. Path → levels → missions/steps (TS). 16. Soft gating with recommended stars (TS). 17. Technique mini-games (L).

**Gamification**
18. Daily goal + streak (TS). 19. Trophies with progress bar (TS). 20. Collectible records (D). 21. Weekly challenge, per-tier leaderboards (D). 22. XP → cosmetics (L). 23. Personal best "beat your best" (TS). 24. Real-world prize hooks (L).

**Analytics**
25. Per-attempt breakdown by control type (TS). 26. Early/late histogram and bias trend (D). 27. Dashboard totals (TS). 28. Replay and ghost compare (L).

**Calibration**
29. Separate audio and input offsets with a guided tap test, per device (TS). 30. Visible hit-window overlay (TS).

**Practice tools**
31. Metronome, count-in, part isolation (TS). 32. Checkpoint restart preserving score (L). 33. No-fail default (TS).

**Community and content**
34. User-charted routines over royalty-free stems (D). 35. Teacher dashboard (L).

**Monetisation patterns seen**
36. Subscription $10–20/mo with cheaper annual; content-tier splits; one-time and lifetime; retailer/hardware bundles.

**Learning science cited by these products:** Melodics (Deep Practice; short regular sessions), Rocksmith (immediate error feedback, 60-day study). Independent: interleaved practice improves timing accuracy vs blocked ([PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4989027/)); spacing beats massing; deliberate-practice meta-analysis ([PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4073287/)). None of the apps implements true spaced-repetition scheduling of drills; a "due today" review queue would be a differentiator.

**Not found:** official ms windows for Rock Band, Taiko arcade, Beat Saber timing, Melodics' exact colour thresholds, Rocksmith+ adaptive thresholds.
